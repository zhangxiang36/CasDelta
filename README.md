# CasDelta

Toolkit accompanying the Casδ (Cas12 family mini-nuclease) engineering study, covering four stages of the analysis pipeline:

1. **Structure-based interaction analysis** — detection and validation of amino-acid–nucleotide interactions from CIF structures;
2. **Mutation recommendation** — ESM-guided candidate variant generation via the *Efficient Evolution* framework (He et al., 2024);
3. **Sanger/ICE allele calling** — indel calling with ICE, followed by allele-frequency extraction and plant-level classification;
4. **Amplicon NGS analysis** — CRISPResso2 output processing and ICE-vs-NGS cross-platform comparison.

## Modules

### 1. Structure interaction analysis

- `interaction_detect.py` — identifies interactions between protein and nucleotide chains from a `.cif` file; writes serialized results to a `.pkl` file.
- `interaction_check.py` — validates and summarizes the interactions generated by `interaction_detect.py`.

### 2. Mutation recommendation (`efficient-evolution/`)

Derived from the published *Efficient Evolution* framework (He et al., 2024). To generate candidate mutations:

```bash
cd efficient-evolution/
bash bin/recommend_modified_batch_esmv1.sh bin/inputs/
```

The command runs without a GPU. Example output tables are provided in `bin/outputs`.

### 3. Sanger indel calling with ICE (`ice/`)

The [ICE](https://github.com/ed.yang/ice/) package is bundled with two wrappers:

```bash
python ice/ice_analysis_single.py   # single Sanger trace
python ice/ice_analysis_batch.py    # batch mode (folder of .ab1 files)
```

Dependencies are listed in `ice/requirements.txt`; a `Dockerfile` is provided. See `ice/README.md` and `ice/DEVELOP.md` for full documentation.

### 4. Allele analysis (`data/Allele_analysis_data/`)

- `call_allele_ICE.py` — runs ICE calling over a batch of Sanger traces.
- `allele_analysis.py` — extracts allele frequencies from ICE outputs (`*.contribs.json`) and classifies edited alleles.
  - Default thresholds: `filter_threshold = 0.05` (allele retained if ≥ 5% of reads), `wt_threshold = 0.05` (wild-type allele definition).
  - Note: update the hard-coded `project_path` at the top of the script to your local repository location.

Processed outputs used for figure panels are stored as `.xlsx` files next to the scripts (`df_mut_allele_analysis.xlsx` per experiment, plus figure-specific tables listed above).

### 5. Amplicon NGS analysis (`data/Allele_analysis_data/multi_target_validation/NGS/`)

- `indel_stat_CRISPRessoWGS.py` — per-sample indel statistics from CRISPResso2 (WGS-mode) outputs.
- `extract_CRISPRessoWGS_info.py` — collects allele-level information from CRISPResso2 runs.
- `Compare_SangerICE_NGS.py` — cross-platform comparison of ICE-derived indel frequencies (Sanger traces) and NGS-derived allele frequencies.

## Requirements

- Python 3.8+
- `pandas`, `numpy`, `tqdm` (allele analysis and ICE wrappers)
- ICE dependencies — see `ice/requirements.txt` (or use the provided Docker image)
- [CRISPResso2](https://github.com/pinellolab/CRISPResso2) for the amplicon NGS module

## Data Availability

Raw Sanger trace files, ICE outputs and amplicon-sequencing results supporting the manuscript are organized under `data/`.

## Citation

If you use this toolkit, please cite the Casδ manuscript (under review) and the underlying methods:

- He et al., *Efficient Evolution of Human Antibodies from General Protein Language Models* (2024) — mutation recommendation module.
- ICE: Synthego, *Inference of CRISPR Edits from Sanger Trace Data* (preprint) — Sanger indel calling. The bundled `ice/` package is the open-source release from [synthego-open/ice](https://github.com/synthego-open/ice); see `ice/README.md` for citation details.
