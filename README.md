# CasDelta

## Overview
CasDelta is a comprehensive toolkit for protein structure interaction analysis (based on CIF files) and protein mutation recommendation. The project combines a custom interaction detection pipeline with an efficient evolution algorithm from the literature to assist in protein engineering and research.

## Directory Structure
CasDelta/

├── efficient-evolution/      # Protein mutation recommendation tool from He, et. al. 2024

├── interaction_check.py      # Interaction between Amino acid and nucleotide result validation script

├── interaction_detect.py     # Interaction between Amino acid and nucleotide detection and generation script

└── README.md                 # Project documentation

## Core Modules

### 1. interaction_detect.py
- **Function**: Identifies interactions between two chains in a protein structure from a CIF file.
- **Input**: A `.cif` file containing the protein structure.
- **Output**: Generates a `.pkl` file (serialized data), which needs to be further processed by `interaction_check.py`.

### 2. interaction_check.py
- **Function**: Checks/validates the interactions generated by `interaction_detect.py`.
- **Input**: The `.pkl` file generated by `interaction_detect.py`.
- **Purpose**: Verifies the accuracy and completeness of the detected interaction information.

### 3. efficient-evolution/
- **Function**: Recommends protein mutations.
- **Note**: This module is derived from a published research paper (Efficient Evolution).

## Usage

### Mutation Testing
To perform mutation testing, run the following script:

~~~bash
cd efficient-evolution/
bash bin/recommend_modified_batch_esmv1.sh bin/inputs/
~~~
This command can run without GPU.

Output Excel files are already saved in bin/outputs
